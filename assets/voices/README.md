# Vaidehi Voice Notes Directory

Place your `.ogg`, `.mp3`, `.m4a`, or `.wav` voice note recordings in this directory.

### Supported formats:
- `.ogg` (Recommended for native Telegram voice note waveform)
- `.mp3`
- `.m4a`
- `.wav`

### Recommended voice clips:
- `greeting.ogg` (e.g. "Heyyy! Kaise ho aap?")
- `flirt.ogg` (e.g. "Tum na sach mein bohot cute ho!")
- `laugh.ogg` (e.g. "Hahaha pagal ho kya!")
- `goodnight.ogg` (e.g. "Chalo so jao ab, good night!")
- `busy.ogg` (e.g. "Assignment kar rahi hoon, thodi der mein aati hoon!")
